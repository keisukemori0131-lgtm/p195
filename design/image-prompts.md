# 画像差し替え用プロンプト（ChatGPT）

リデザイン後のサイトで「図版（SVG）のまま」になっている画像を、写真などに差し替えるためのプロンプト。

## 方針

- **代表者の写真をもとに加工した画像は使わない**。ChatGPT に代表者の写真を添付しない。人物を入れる画像は「顔が写らない」構図にし、特定の人に似せない
- 代表者の写真が入っていた場所（トップの「会社紹介」）は、SVG で作った図版に置き換え済み（`public/images/about/ishikari-night.svg`：石狩湾の夜・石狩灯台・軌道を描く月・名刺の色ブロック）
- 会社概要と記事の「この記事を書いた人」の小さな写真は、いただいた写真をそのまま使っている（加工なし）

## 使い方

1. ChatGPT の新しいチャットに、**リデザインしたトップページのスクリーンショットを添付**する（色味を合わせるため）
2. 「共通部分」＋作りたい画像のプロンプトを貼り付けて送る
3. できた画像を指定のファイル名で保存して渡してもらえれば、こちらで差し替える

| No | 置き場所 | ファイル名 | サイズ |
|----|----------|------------|--------|
| 1 | サービス「求人情報コンサル」（トップのカード・サービスページ） | `public/images/services/recruit.webp` | 1600×1200（4:3） |
| 2 | サービス「REGOLITH ORBIT」 | `public/images/services/orbit.webp` | 1600×1200（4:3） |
| 3 | サービス「101FIT」 | `public/images/services/fit.webp` | 1600×1200（4:3） |
| 4 | SNS でシェアしたときの画像（OGP） | `public/og-image.png` | 1200×630 |
| 5 | （任意）お知らせ・コラムのサムネイル | UpNote の管理画面から登録 | 1600×900（16:9） |

> 1〜3 はトップのカードでは**横長（16:7）に切り抜いて**表示する。大事なものは画面の中央の帯に入れる。

---

## 共通部分（毎回いちばん上に貼る）

```text
添付したのは、株式会社レゴリス（北海道石狩市）のホームページのデザインです。
このサイトに載せる写真を1枚作ってください。

# 雰囲気
- 落ち着いた、信頼感のある、少し静かな写真。広告っぽい派手さや作り笑顔はいらない
- 色味はサイトに合わせて、濃い紺・白・明るいグレーが中心。差し色として、朱赤・黄・緑・青のどれかが小さく入る程度
- 自然光。コントラストは控えめ。彩度は少し低め
- 北海道の地方都市の、実在しそうな普通のオフィスやジム。高級すぎない

# 必ず守ること
- 人物の顔は写さない（手元・後ろ姿・肩越し・ピントの外れた遠景だけ）。実在の人物に似せない
- 画像の中に文字・ロゴ・社名・看板の文字を入れない（画面の中の文字もぼかす）
- 大事なものは画面の中央の横帯に置く（上下が切れても伝わるように）
- 写真1枚だけ。コラージュ、枠、余白、角丸は付けない
```

## 1. 求人情報コンサル（recruit.webp）

```text
# 作る画像：求人情報コンサル（求人原稿の作成・改善）
- 横長 4:3、1600×1200px
- 明るいオフィスの打ち合わせテーブル。2人が向かい合って、印刷した求人原稿に赤ペンで書き込みながら相談している「手元」のアップ
- テーブルの上には、求人原稿の紙、ノートパソコン（画面はぼかす）、コーヒーカップ
- 片方の手が原稿の一部を指している。話し合いながら一緒に直している感じ
- 背景は白い壁と窓。窓の外にうっすら北海道らしい冬の空
```

## 2. REGOLITH ORBIT（orbit.webp）

```text
# 作る画像：REGOLITH ORBIT（ホームページ制作・運用）
- 横長 4:3、1600×1200px
- 木のデスクの上に、ノートパソコンとスマートフォン。パソコンにはホームページの管理画面（グラフや一覧が並ぶ、紺と白の画面）、スマートフォンにはチャットアプリの画面
- 画面の中の文字は読めないようにぼかす。グラフや四角い部品の形だけが分かる程度
- 手前に人の手がスマートフォンを持っている（顔は写さない）
- 背景は明るいグレーの壁と観葉植物を少し。全体にすっきり
```

## 3. 101FIT（fit.webp）

```text
# 作る画像：101FIT（パーソナル＋24時間ジム）
- 横長 4:3、1600×1200px
- 地方都市の小さめの、清潔なトレーニングジムの室内。ダンベルラックとトレーニングマシンが並んでいる
- 黒いマシンとグレーの床、白い壁。照明は落ち着いた暖かい色
- 人は写さないか、遠くに後ろ姿が1人だけ（ピントは外す）
- 高級ホテルのジムのようにはしない。地域の人が通う、親しみのあるジム
```

## 4. OGP 画像（og-image.png）

```text
# 作る画像：SNS でシェアしたときに表示される画像
- 横長 1200×630px
- 背景は濃い紺の夜空に小さな星。右側に大きな灰色の月と、月を囲む細い白い軌道の線（添付のトップページと同じ雰囲気）
- 左端に、名刺の色ブロック（上から朱赤・黄・緑・紺・青・臙脂・黒）を縦に並べた細い帯
- 左側に白い文字で：
  1行目（明朝体・大きく）「事業を、次の軌道へ。」
  2行目（ゴシック体・小さく）「採用・集客・健康づくり。石狩から。」
  下に（太いゴシックの欧文）「REGOLITH」と小さく「株式会社レゴリス」
- 文字は画面の端から 60px 以上内側に置く（SNS で端が切れても読めるように）
- ※この画像だけは文字を入れてよい
```

## 5.（任意）お知らせ・コラムのサムネイル

記事ごとに作る場合のひな形。【】の中を記事に合わせて書き換える。

```text
# 作る画像：コラム記事のサムネイル
- 横長 16:9、1600×900px
- 記事のテーマ：【例：求人原稿で最初に見直したい3つのポイント】
- 描くもの：【例：求人原稿の紙に赤ペンでチェックを入れている手元】
- 文字・ロゴは入れない。人物の顔は写さない
- 一覧ページで他の記事と並べたときにそろうよう、明るいグレーの背景・自然光・彩度低めで統一する
```

---

## 差し替えのときにこちらでやること

- 受け取った画像を WebP に変換して軽くし（1600px 幅・80% 程度）、`src/constants/services.js` の `cover.src` を差し替える
- トップのカードで切れてほしくない位置があれば、`object-position` で調整する
- OGP 画像は `public/og-image.png` を置き換えるだけ（ファイル名はそのまま）

# 月と宇宙の背景 差し替え用プロンプト（ChatGPT）

今の月（SVG フィルタで描いたもの）と宇宙の背景（CSS で打った点の星）を、写真品質の画像に差し替えるためのプロンプト。

## 差し替えるもの

| No | 画像 | 使う場所 | ファイル名 | サイズ |
|----|------|----------|------------|--------|
| 1 | 月（背景が透明） | ファーストビュー・各ページの見出し帯・記事の見出し帯・相談の案内（左下）・404・会社概要 | `public/images/brand/moon.png` | 1024×1024（正方形） |
| 2 | 宇宙の背景（広い） | ファーストビュー・相談の案内 | `public/images/brand/space-wide.webp` | 1536×1024（横長） |
| 3 | 宇宙の背景（細長い） | 各ページの見出し帯・記事の見出し帯 | `public/images/brand/space-band.webp` | 1536×1024（横長。上下を切って使う） |

- **月を囲む白い軌道の線と小さな白い点は、今までどおりコードで描く**（画像には入れない。線がくっきりしたまま、大きさが変わってもぼやけない）
- 背景の上には白い文字（見出し・ボタン）が乗るので、**左側は暗く静かに**しておく
- ChatGPT の最大サイズは 1536px 幅なので、こちらで画面幅いっぱいに引き伸ばして使う。星がにじまないよう、星は小さく・数は控えめにしてもらう

## 使い方

1. ChatGPT の新しいチャットに、**今のトップページのスクリーンショットを添付**する（色と配置を合わせるため）
2. 「共通部分」＋作りたい画像のプロンプトを 1 つ貼り付けて送る
3. できた画像をそのまま渡してもらえれば、こちらで変換・差し替え・見た目の調整をする

## 共通部分（毎回いちばん上に貼る）

```text
添付したのは、株式会社レゴリス（北海道石狩市）のホームページです。
社名のレゴリスは「月の表面を覆う砂」、サービス名の ORBIT は「軌道」の意味で、サイト全体を「夜の宇宙と灰色の月」で表現しています。
今の月と宇宙の背景が安っぽいので、写真品質の画像に差し替えたいです。1枚作ってください。

# 全体の雰囲気
- NASA や天文台が撮った写真のような、本物らしい質感。CG っぽさ、ゲームっぽさ、イラストっぽさは避ける
- 静かで上品。企業サイトの背景として、文字の邪魔をしない
- 色は濃い紺〜黒が中心。紫・ピンク・緑の派手な星雲や、強い光の筋（レンズフレア）は入れない
- 画像の中に文字・ロゴ・線・枠は入れない
```

## 1. 月（moon.png）

```text
# 作る画像：月
- 正方形 1024×1024px、PNG、**背景は完全な透明**（月の外側に星や黒い背景を入れない）
- 満月を真正面から見た写真。画像の中央に置き、上下左右に少しだけ余白を残す（月の直径は画像の幅の 90% くらい）
- 色は灰色（ほぼ無彩色）。黄色やオレンジに色づけしない
- 光は左上から当たっていて、右下のふちが少しだけ暗い（真っ黒な影の部分は作らない）
- 海（暗い模様）とクレーターがはっきり見える、解像感の高い写真。のっぺりさせない
- ふちはくっきり。月のまわりに光のにじみ（グロー）は付けない（光はこちらで足す）
- 月を囲む輪や線は描かない
```

## 2. 宇宙の背景・広い（space-wide.webp）

```text
# 作る画像：ファーストビューの背景（宇宙）
- 横長 1536×1024px
- 深い紺〜黒の夜空。上の方がより暗く、下に向かってわずかに青みのある紺になるグラデーション
- 星は「小さく、細かく、まばら」に。ところどころに少しだけ明るい星。大きくにじんだ星は入れない
- 右側の中央あたりに、天の川のような、ごく淡い青白い光の帯をうっすらと斜めに（目立たせない。紫やピンクは入れない）
- **左半分は暗く静か**にする（ここに白い見出しと白いボタンが乗る）
- 右半分の中央はやや空けておく（ここに月を重ねる）。月や惑星そのものは描かない
- 地面・山・建物・人工物は入れない
```

## 3. 宇宙の背景・細長い（space-band.webp）

```text
# 作る画像：各ページの見出し帯の背景（宇宙）
- 横長 1536×1024px（こちらで上下を切って、横長の細い帯として使う。大事なものは画面の中央の横帯に置く）
- 2. と同じ空の続きに見えるように、深い紺〜黒・小さくまばらな星
- 天の川のような淡い光は、右寄りに、さらに控えめに（ほとんど見えないくらい）
- 左側は暗く静かに（白い大きなページ名とパンくずが乗る）
- 月や惑星、地面、人工物は描かない
```

## うまくいかなかったときの追加の指示

**月の背景が透明にならない（黒い背景が付いた）**

```text
月はそのままで、背景だけを完全な透明にした PNG で出し直してください。月のふちに黒い線や白いにじみが残らないようにしてください。
```

**月が黄色っぽい・CG っぽい**

```text
色をほぼ無彩色の灰色にして、NASA の満月の写真のような本物らしい質感にしてください。クレーターと海の模様がくっきり見えるように、解像感を上げてください。
```

**背景が派手すぎる**

```text
星雲の色を消して、深い紺〜黒の夜空に小さな星がまばらにあるだけの、もっと静かな背景にしてください。左半分はさらに暗くしてください。
```

## 受け取ったあとにこちらでやること

- 月: 透明を保ったまま WebP に変換して軽くし、`MoonOrbit.jsx`・相談の案内・404 の月を差し替える。月のふちのにじみ（グロー）は CSS で足す
- 背景: WebP に変換し、`.space`（CSS で打った点の星）を画像に置き換える。文字が読めるよう、左側に暗いグラデーションを重ねて調整する
- トップの「会社紹介」の石狩湾の SVG の月も、同じ月の画像に合わせるか確認する（SVG の中に画像を埋め込むか、写真の月を重ねる）

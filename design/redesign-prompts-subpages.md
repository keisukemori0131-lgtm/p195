# 下層ページ リデザイン用プロンプト（ChatGPT）

トップの案（ネイビー×パール・月・名刺の色ブロック）に合わせて、下層ページを作るためのプロンプト。

## 使い方

1. ChatGPT の**新しいチャット**に、**採用したトップの画像を添付**する
2. 「共通部分」＋作りたいページのプロンプトを 1 つ、続けて貼り付けて送る
3. 1 チャットにつき 1 ページ。同じチャットで続けて作る場合は「共通部分」を省き、ページのプロンプトだけ送れば良い
4. 文字がつぶれたら、末尾の「補足プロンプト」で上下 2 枚に分けてもらう

---

## 共通部分（毎回いちばん上に貼る）

```text
添付した画像は、株式会社レゴリス（REGOLITH Inc.／北海道石狩市）のホームページのトップページのデザインです。
このデザインを気に入ったので、同じデザインのまま下層ページのデザインカンプを作ってください。PC版、横幅1440px、1枚の縦長画像でお願いします。

# トップから引き継ぐもの（変えない）
- ヘッダー：左に色ブロック＋「REGOLITH」＋小さく「株式会社レゴリス」、右にメニュー「サービス・会社概要・お知らせ・コラム・お問い合わせ」と黒いボタン「相談する →」。いま表示しているページのメニューにだけ、下に細い線を引く
- 色：濃いネイビー（ファーストビュー、ORBIT、最後の相談の案内の背景）、パール（明るいグレーのセクション）、白（カード）、名刺の色ブロック（朱赤・黄・黄緑・緑・紺・青・臙脂・黒）はアクセントにだけ使う
- 文字：和文の見出しは明朝体、本文はゴシック、小さな英字ラベル（例「REASON ——」）は大文字＋右に短い線
- パーツ：白いカードの左上の縦の色線、黒い四角ボタン、白い枠線だけのボタン（暗い背景の上）、「一覧を見る →」のテキストリンク、色ブロックの小さな横帯
- 最後の相談の案内とフッターは、トップと同じものをそのまま置く
  （見出し「人が来ない、問い合わせが来ない。その悩みから、話しましょう。」／ボタン「フォームで相談する」「電話で相談する 0133-76-6751」）

# 下層ページの共通の見出しエリア
- ヘッダーの下に、トップのファーストビューを低くした「ページの見出し帯」を置く（高さはトップの半分くらい）
- 濃いネイビーの背景、右側に小さめの月と細い軌道の線、左端に色ブロックの縦帯
- 左に、小さな英字ラベル、大きな明朝のページ名、その下にパンくずリスト「TOP ＞ ページ名」

# 実装しやすくするためのルール（必ず守る）
- 中身は中央の幅1200pxにおさめ、12カラムのグリッドにそろえる。セクションの上下の余白はトップと同じにする
- 背景は単色か、2色のシンプルなグラデーションまで。テクスチャや写真のコラージュは使わない
- 文字を写真の上に重ねない。斜めのレイアウト、要素が浮いている配置、3Dの表現は使わない
- カード、ボタン、見出しの形はトップと同じものを使い回し、新しい形のパーツを増やさない
- 写真を入れる場所は、内容が分かる程度の写真かグレーの枠でよい
- 日本語は指定した文言をそのまま使う。架空の数字、実績、お客様の声は入れない
- 記事のタイトルや日付など中身が決まっていない部分は、それらしい仮の文言でよい（日付は2026年）
- スマホでは1列に並べ直せる構成にする
```

## 1. サービス

```text
# 作るページ：サービス（/services）
見出し帯：英字ラベル「SERVICES」、ページ名「サービス」

1. 導入：英字ラベル「SERVICES」、見出し「採用に困ったら。集客に困ったら。まずはレゴリスへ。」

   その下に、ページ内の各サービスへ移動する目次カードを3枚、横に並べる（番号・サービス名・ひとことの説明）
   - 01 求人情報コンサル／「求人を出しても応募が来ない」を、原稿から変える。
   - 02 REGOLITH ORBIT／つくって終わりにしない。公開してからが本番のホームページ。
   - 03 101FIT／私たちの提案が生まれる、実践の現場。

2. 01 求人情報コンサル（白い背景）：左に文章、右に打ち合わせの写真
   英字ラベル「ADVERTISING AGENCY / RECRUIT」、大きな番号「01」、サービス名、上のキャッチ、説明文
   その下にカード3枚：「伝わる求人原稿をつくる」「応募が来ない原稿を立て直す」「掲載から応募まで支える」（それぞれ短い説明文つき）

3. 02 REGOLITH ORBIT（パールの背景）：左右を入れ替えて、左に管理画面のスクリーンショット、右に文章
   英字ラベル「ADVERTISING AGENCY / WEB」、サービス名、小さく「ホームページ制作・運用」、キャッチ、説明文、「公式サイトを見る →」
   その下に「REGOLITH ORBIT の機能一覧」：7つのタブ「更新・問い合わせ対応・予約・解析・集客・SEO・リピート・基盤」を横に並べ、「更新」タブが選ばれている状態にする
   タブの下に、ひとこと「更新が止まったホームページを、毎日の延長で動かせるように。」と、変化を表すカードを2列で並べる。各カードは「機能名」「困りごと（グレーの文字）」→「こう変わる（黒の文字）」の3段。例：
   - LINEからお知らせ投稿／更新が後回しになり、情報が古いまま → 文章と写真をLINEで送るだけ。AIが整えて掲載します
   - AIコラム自動生成（週1回）／ブログを書く時間がとれない → 週1回、AIがコラムを自動で作成します

4. 03 101FIT（白い背景）：左に文章、右にジムの写真
   英字ラベル「FITNESS GYM / ICHI MARU ICHI」、サービス名、小さく「パーソナル＋24時間ジム」、キャッチ、説明文
   所在地「北海道石狩市樽川3条1丁目19」、ボタン「アクセスを見る」「公式サイトを見る →」

5. 締め（パールの背景、中央ぞろえ）：明朝の大きめの文字「どのサービスが合うか分からなくても大丈夫です。今の困りごとをそのまま聞かせてください。」
6. 最後の相談の案内、フッター（トップと同じ）
```

## 3. お知らせ一覧（コラム一覧も兼用）

```text
# 作るページ：お知らせ一覧（/news）
見出し帯：英字ラベル「NEWS」、ページ名「お知らせ」

1. 一覧の見出し：英字ラベル「NEWS」、見出し「お知らせ一覧」
   説明「サービスに関するお知らせや、運営するジム「101FIT」の情報などを掲載しています。」
   右端に件数の表示「全 12 件 ― 10 件を表示・1/2」

2. 最新の記事（LATEST）：横幅いっぱいの大きな白いカード1枚。左に写真（横長）、右に「LATEST」のラベル、日付、カテゴリのラベル、タイトル（明朝で大きめ）、本文の書き出し2〜3行、「続きを読む →」

3. 過去のお知らせ：小見出し「過去のお知らせ」。その下に白いカードを3列で9枚並べる
   各カードは上に写真（横長）、下に日付・カテゴリのラベル・タイトル（2行まで）。カードの形はトップのコラムのカードと同じにする

4. ページ送り：中央に「← 前へ　1　2　次へ →」。いまのページの番号だけ黒い四角で塗る

5. 最後の相談の案内、フッター（トップと同じ）
```

> コラム一覧はレイアウトが同じ。上のプロンプトの「お知らせ」を「コラム」に、英字ラベルを「COLUMN」に、説明を「採用・集客・ホームページ運用・健康づくりについて、現場で役立つ考え方をお届けします。」に置き換えれば作れる（説明文は仮。いまのサイトの文言に合わせて調整）。

## 補足プロンプト

**文字がつぶれたとき**

```text
同じデザインのまま、ページを上下2枚に分けて出し直してください。文字はすべて読める大きさで。
```

**スマホ版**

```text
このページのスマホ版（横幅375px）を作ってください。レイアウトは1列に並べ直すだけにして、色・フォント・パーツの形は変えないでください。ヘッダーはロゴとハンバーガーメニューだけにしてください。
```

**実装用の仕様（全ページのデザインが決まった後に、トップのチャットで）**

```text
このデザインを実装するための仕様を、カラーコード、フォントとサイズ、余白、角丸、影、ボタン・カード・見出しの各パーツの寸法、セクションごとのレイアウト（グリッドの何カラムを使うか）の一覧にしてください。
```

## トップの案を実装するときに直すところ（画像から読み取った注意点）

- **代表者の写真は画像生成の別人**。実装では今の本物の写真（RepCard で使っている写真）を使う
- **お知らせ・コラムの中身（2024年の日付、記事タイトル）は架空**。実装では UpNote の実データを出す
- 選ばれる理由のカード説明や会社紹介の本文は、ChatGPT が文言を少し書き換えている。今のサイトの文言（`USP_CARDS` など）を使う
- 選ばれる理由のアイコン（握手・モニター・人）と ORBIT 機能の丸いアイコンは、実装ではアイコンフォントか SVG で近いものを当てる
- ファーストビュー右端の縦書きの英字（REGOLITH Inc. / RECRUIT WEB HEALTH ISHIKARI）は仮の飾り。使うかは代表に確認
